# Black Hole Simulation

This project is a Python-based simulation comparing two different black hole evolution models:

1. Hawking Radiation Model  
2. Environmental Interaction Model

The Hawking model demonstrates continuous mass loss and eventual evaporation, while the custom model explores how environmental energy exchange could affect black hole behavior over time.

The project was created as an independent conceptual exploration and is not intended to represent a fully physically validated theory.
